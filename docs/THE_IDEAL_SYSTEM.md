# 理想系统：完整设计与架构（做减法的底图）

2026-08-09。这份文档写出**完整的理想系统**——每个组件标注现状、被什么需求逼出、依赖什么、
砍掉损失什么——然后给出预设的减法线。目的：让减法在依赖图上做，而不是在印象上做。

状态标记：✅ 已有且有测试 · 🔶 半成品（存在但饿着/未接线）· ⬜ 纯设计（只在讨论里）· ❌ 已删除

---

## 1 · 系统一句话

> 一个以**可问责审阅**为工作单元的病历审阅系统：**合同**声明每个答案欠什么；**审阅者**收集
> 证据（唯一接触病历的层）；**判断层**在证据上组合出答案（不读病历，可离线测试）；**裁判者**
> 核验主张（缺席主张只能靠独立反向检索）；**度量平面**测过程而不只是答案；**开发循环**让合同
> 在几乎无标注的情况下收敛，并自己知道何时该停。

```
                ┌──────────────────────────────────────┐
                │           P1 合同（人机共读）           │
                │  字段 · 决策/冲突规则 · 证据规则 · 义务   │
                │  enforcement tiers：强制/渲染/可背离     │
                └────────┬──────────────────┬──────────┘
                    编译 ↓                   ↓ 渲染进提示
     ┌─────────┐   ┌──────────┐       ┌──────────┐
     │ 病历/语料 │ ← │ 编译臂 D/C │       │ 审阅者 B  │ → 缺口台账(观测)
     └─────────┘   └────┬─────┘       └────┬─────┘   线程台账(有牙)
                        ↓                   ↓
                P2 四元组集合：(文档, 字段, 值/缺席, Standing)
                        ↓
                P4 判断层：佐证 | 仲裁 | 去重排序 | 推导
                P6 分层推断：声明规则 + 标记的自由推断
                        ↓
                答案 + 义务履行记录（witness/覆盖/排除/标记）
                        ↓
                P7 裁判者：确定性审计 | 对抗核验 | 分诊
                        ↓
                P8 flag / 答案 / 有理由的弃答
    ────────────────────────────────────────────────────
    M 度量平面：镜像对 · 四臂 · 过程度量 · 弃答计分 · 判定类别隔离
    D 开发平面：探针 → 熵 → B−C 分歧 → 仅裁决分歧 → 晋升 → 停止
```

三个平面的分工：**产品平面**（P）出 flag；**度量平面**（M）证明 flag 可信；**开发平面**（D）让
造 P 的过程便宜且会收敛。三个平面对应 R01 的三个假设：H1 过程效度（M2）、H2 自适应边界（M3）、
H3 无标注收敛（D1+D2）。

## 2 · 产品平面（P）

### P1 · 合同 ✅（核心机制全部已有）

| 子件 | 现状 | 说明 |
|---|---|---|
| 字段/决策规则/冲突规则 YAML | ✅ | 5 份合同（4 STORE + class of case） |
| discriminating facts + `turns_on` 强制声明 | ✅ | 加载器**拒绝**不声明依赖事实也不给理由的冲突规则 |
| 结局空间 + kind→义务绑定 | ✅ | value 欠 witness；abstain_evidence 欠覆盖；abstain_spec 豁免覆盖欠路由报告 |
| enforcement tiers（强制/渲染/可背离） | 🔶 | 事实上存在（`enforced_elements` + 两个提示测试守护），**未提升为域语言的一等条目** |
| 提示注册表（每块可消融、进 arm hash） | ✅ | |

**被什么逼出**：R3（可信）+ R7（跟得上演化）+ "人机读同一份"。
**砍掉损失**：一切。P1 是不可砍的地基。

### P2 · 直接证据层（四元组）🔶

定义 ✅（Standing 三分，per-document-per-field，CONTEXT.md）；**实现是文档类型代理**
（`strata[].establishes`），不是逐文档判断。已知缺口：类型上 can-establish 的病理报告可能说的
是另一个肿瘤/是外院复述。

**被什么逼出**：两层架构——归因的干净二分（四元组错=证据层；四元组对答案错=判断层）。
**砍掉损失**：错误分析回到"人读轨迹讲故事"。
**减法选项**：保留类型代理（承认误差）是合法的第一层——升级为逐文档 Standing 判断可以推迟。

### P3 · 审阅者 ✅

deepagents 运行时、search/read 工具面、覆盖台账、gate、线程台账（有牙：解决或给理由的驳回，
均入 manifest）、缺口台账（无牙：纯观测，`write_todos`，每次运行约 2 写）。
双台账**分属两个通道**（行动/信念），不可合并——同一事实的两个测量面，允许不一致本身是信息。

**砍掉损失**：没有审阅者就没有轨迹，没有轨迹就没有整个度量平面。
**减法警告**：曾想砍线程台账的牙——错误；牙是产品的 warrant 机制，台账无牙是仪器的纯净性。

### P4 · 判断层组合算子

| 算子 | 现状 | 说明 |
|---|---|---|
| 佐证（多来源同一命题，强度叠加） | ✅ | strata/witness policy |
| 仲裁（冲突值，规则选一） | ✅ | conflict rules + discriminating facts |
| 去重 + 排序（事件同一性） | ⬜ | 时间线任务的前提；文献名 event coreference |
| 推导（无文档断言答案） | ⬜ | 分期组、class of case；影子存在于一条 `no_discriminator` |

**减法建议**：算子三、四整体推迟——它们只被时间线/class-of-case 任务需要，是 Ring 3。

### P5 · 弃答结构 ✅ / ⬜

四个 kind ✅。**第三种缺席**——"证据可能在别处"（碎片化的单系统诚实表达）⬜。
**被什么逼出**：缺口一（没做的治疗）+ R4b。
**砍掉损失**：砍 kind 机制 = 砍掉 accountable 的一半；砍"在别处"只损失 R4b 的标书内版本。

### P6 · 分层推断 ⬜（整体纯设计）

DOCUMENTED / INFERRED / ABSENT / CONTRADICTED 四结局；INFERRED 欠"前提逐条 witness + 对
竞争候选的排除"；声明规则（确定性检查）+ 标记的自由推断（需裁决）；自由推断反复出现→晋升为声明
规则。前提全是四元组 ⇒ 推断住在判断层，两层架构不破。

**被什么逼出**：缺口二（没写的原因）——人类金标准本身就是推断的，禁止推断的合同追不上它。
**砍掉损失**：原因归因整个不可做 ⇒ P8 的 flag 定义退化 ⇒ 临床干预暴露于 alert fatigue。
**减法选项**：可以只做"声明规则"一级（放弃自由推断+晋升），损失长尾但保住架构。

### P7 · 裁判者

| 角色 | 现状 | 说明 |
|---|---|---|
| 确定性过程审计 | 🔶 | 原料全在盘上没人读：search hits 的 note_id、read 返回的全文（`result["text"]` 无消费者）、`suspected_recognition_failures` 在记无人读。found/read/cited 三布尔 = 一张失败模式表 |
| 对抗核验器（带工具，独立反向检索缺席主张；驳倒立场；不看金标准） | ⬜ | 核验不对称性：阳性=查 witness（代码）；缺席=只能再搜一遍（必须 agentic）；推断=前提+反证+排除 |
| 分诊（可以看分歧——诚实例外） | 🔶 | `bad_case_triage` 维度已在 judge.py |

判定类别隔离 ✅：JUDGED 与 DETERMINISTIC 不得平均；裁决者与被评者分离（meta_evaluation）。

**被什么逼出**：R3——flag 要扛住"你凭什么"；缺席主张的可核验性。
**砍掉损失**：砍确定性审计=度量平面塌一半（它便宜，别砍）；砍对抗核验器=缺席主张回到自证。

### P8 · flag 定义 ⬜

> flag = 非一致 ∧ 无记录且不可推断的正当理由，"无"字经独立反向检索核验。

**被什么逼出**：R4a + 临床 Aim 2 的生存（alert fatigue）。依赖 P6 + P7。纯组装，无独立机器。

## 3 · 度量平面（M）

### M1 · 金标准 🔶

答案金标准 ✅（合成语料 27 例）。**gold_evidence（哪份文档立住答案）：schema ✅，实例为零**——
四个已写好的消费者全部饿着（检索召回分母、读了没引用、失败归因 RETRIEVAL_FAILURE/SPEC_AMBIGUITY、
found 判定）。合成语料上打标零成本（生成器构造时已知，`establishes=` 参数）。
**打标纪律**（交接文档）：先落验证测试（被标 note 必须携带 gold 值），增量打标，未标=ABSENT 不是 clean。

### M2 · 镜像对 + kill condition 🔶

SYN0001/SYNX03 镜像对 ✅（含 `_ground_truth.json`）；`establishes=` 打标 ⬜。
**验收 = H1 的硬性终止条件**：同形答案必须打出不同过程判定；不能区分即仪器无效，主张收缩。
**这是全系统唯一不可推迟也不可砍的验收。**

### M3 · 四臂阶梯

| 臂 | 现状 |
|---|---|
| B 完整 agent | ✅ |
| A 固定词表+读全部命中+单次调用（`query_only`，同一评分器强制） | ✅ |
| C 模型自写查询、单轮 | ⬜（A 的小变体，几十行） |
| D 零模型（正则+词典+硬编码规则） | ⬜（合成语料上约两百行） |

C−A = 查询构造的价值（已有先验证据：五词表漏 31.7% 患者，模型自提的词被系统删掉）；
B−C = 自适应循环的价值（预注册：随算子级别分层）。**D 不做就答不了"为什么不用传统 NLP"。**

### M4 · 过程度量 ⬜（原料全部已有）

**Complete Answer**：缺口台账（SELF_REPORTED："它知道要查"）× 检索轨迹（DETERMINISTIC：
"它真查了"）二维交叉 → 四格表，最后一格（不知道也没查）= 捷径。原料：rule_catalog 的
`discriminating_fact.{fid}` 稳定 id ✅、台账 ✅、轨迹 ✅——只缺读它们的函数。
**弃答计分**：弃答自己的 P/R + 提示敏感性报告。
**已知风险**：可能全绿（先行测量 42 次运行检索失败为零）——kill condition 预设；四臂下全绿仍是
"该谱系无过程差异"这一发现。

### M5 · 评分平面 ✅

evals、REGISTRY（声明确定性的行必须指名决定它的代码）、arm hash、manifest。

## 7 · 预设的减法线（环）

依赖方向：外环依赖内环，砍只能从外往内。

**Ring 0 · 不可砍的核**
P1 合同（含 kind→义务）· P2（类型代理版即可）· P3 审阅者 · P4 算子一二 · M2 镜像对验收 ·
M5 评分平面 · I1/I2/I6。
——没有这个环就没有"可问责"三个字。

**Ring 1 · 论文最小集（npj 那篇 = R01 preliminary data）**
Ring 0 + M1 `establishes=` 打标（只标镜像对）+ M3 全四臂 + M4 Complete Answer 与弃答计分 +
D1 熵命令接线 + P7 确定性审计（读盘上已有的 found/read/cited）。
——交付：H1 验收 + 四臂过程-成本报告 + 无标注清晰度信号。**全部原料已有，纯接线与打标。**

**Ring 2 · R01 完整集**
Ring 1 + P6 分层推断 + P7 对抗核验器 + P8 flag + P5"在别处"弃答 + D2/D3 收敛循环 +
肺癌修订史重放 + I4 CRC 语料与镜像对 + **I3 PHI 重新自动化**。
——交付：H2/H3 + 临床 Aims 的接口（flag、分诊）。

**Ring 3 · 后续/第二篇**
P4 算子三四（时间线、推导）· I5 多存储/桥接（INPC 全景）· D4 晋升自动化 · D6 卡片度量 ·
P2 升级为逐文档 Standing 判断。
——每一项都有独立的科学价值，但都不挡 Ring 1/2 的路。

**减法的三条纪律**（从这个仓库自己的历史提炼）：
1. **按环砍，不按组件砍**——依赖图上悬空的组件会以更差的形式长回来；
2. **每砍一刀写一份判死文档**（CANDIDATE_LEDGER_REMOVED.md 的先例）——记录砍掉的主张和
   它的数据，防止复活也防止遗忘；
3. **不砍 kill condition**——验收可以推迟，验收的标准不能松。
