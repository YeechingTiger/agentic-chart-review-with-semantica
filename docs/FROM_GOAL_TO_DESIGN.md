## 1 · 终极目标：三个高度

| | 目标 | 谁的 |
|---|---|---|
| **G1 · 健康** | 结直肠癌患者获得指南一致的治疗——或**深思熟虑的、有记录的**偏离 | 患者 / 卫生系统 |
| **G2 · 系统** | 一个反馈回路：把**沉默的偏离**变成"纠正"或"有记录的决定"，且快到还来得及改 | 整份标书（临床方已用 "feedback loop" 写出） |
| **G3 · 测量** | 每患者、及时、可信、公平的一致性判定 | 方法学 Aim（本文的主题） |

**核心重述：敌人不是偏离，是沉默的偏离。** 有些偏离是对的——禁忌、患者意愿、合理的临床判断。目标不是 100% 一致率，而是**零沉默偏离**：没人注意到、没人决定过、没人记录过的那种。这个重述决定了后面的一切：为什么"原因"必须进入测量，为什么"没有证据"必须有理由，为什么临床干预叫 accountable justification。

## 2 · 临床缺口：回路今天断在哪

### 2.1 测量太慢

登记数据的现行标准：诊断年结束后 **22 个月**提交、**27.5 个月**报告 `[SNIPPET, JNCI Monographs 2024;(65):123]`。质量改进因此"生来就是回顾性的"。SEER 的实时报告试点把目标压到 2 个月，但 2 个月的病例合并**结构性地不含分期与首程治疗**——因为那时治疗尚未发生。**这不是技术问题，是时间问题：没有任何模型改进能修好一个源文档尚不存在的变量。**（⚠ 元素清单的排除是摘要推断，须查原文。）

### 2.2 测量太贵

人工抽取约 **1 小时/患者** `[SNIPPET, Wornow et al., NEJM AI 2024]`。监督式 NLP 的替代同样贵：一个新概念族约需 **1,000 份**多层标注病历 `[SNIPPET, Steinkamp et al., JBI]`；已训好的模型换一家医院还要约 **700 份**本地标注 `[SNIPPET]`。表型学界自己的判词：逐变量标注对成百上千个变量 **"infeasible"** `[SNIPPET, PheNorm / MAP]`。而 NCCN 指南年年改版，精准肿瘤学在加速它——**测量的维护成本是复利的**。

### 2.3 测量的单位错了

登记和质量项目产出**人群比率**；反馈回路需要**逐患者的 flag**，送到还能改变该患者治疗的人面前。被动报表无效是实施科学的成熟结论。

### 2.4 测量不回答"为什么"

干预设计需要区分偏离的原因：拒绝 / 禁忌 / 临床判断 / 可及性 / 记录缺失。登记标准里为此设有编码字段（如 Reason for No Surgery，含"未知"这一合法编码），**文献中对这类字段的 NLP 工作为零**（阴性检索结果）。原因常常没有被任何文档明确书写——它必须从事件模式中**推断**，而无标记的推断等于幻觉。

### 2.5 测量被就医碎片化污染

辅助化疗在社区肿瘤科完成，单一机构的记录就显示"未化疗"→ 表观非一致。碎片化与农村居住、保险状态相关，**因此这个测量误差是差异性的：现有发表的一致性差异估计，部分是测量假象**。追到外部证据需要的查询词与目的地本身来自病历内容——固定管线在原理上够不着。

### 2.6 质量的定义里只有答案，没有过程

所有现存 QA——登记再抽取、CMS 的 DEAR/CAAR、HEDIS over-read、试验的源数据核查（SDV）——**测量单位都是字段值的一致率，从来不是证据路径**（阴性检索结果，三个相邻领域独立确认）。SDV 预设正确的源已被找到，结构上无法发现"从未打开的关键文档"。而正确答案可以来自错误过程：医学生正确诊断中约 **7%** 建立在错误推理上 `[SNIPPET, "Guessing right", 2 hosts]`。唯一做过"没看 vs 看了但判错"这个切分的医学分类学是放射学的 Kundel 眼动研究——对像素，从未对文档。

### 缺口总结：三种"没有"

> 现有临床 NLP 回答"记录了什么"。一致性判定由三个它不回答的问题决定：
> **1. 没做的治疗**——一致性的分母由缺席主张构成，而抽取系统对"没找到"不欠任何义务；
> **2. 没写的原因**——偏离是否正当决定 flag 是否该发，而原因必须被推断且推断必须可审计；
> **3. 不在这里的证据**——外部治疗让"没做"和"在别处做了"在单系统记录里长得一模一样。

## 4 · 发散：满足 R1–R4/R7 的六条平行路线

|---|---|---|---|---|
| **A · 提速登记** | 让登记本身快起来 | SEER 实时报告（2 个月 CTC） | R1 | 结构性缺 R2 的关键变量：治疗还没发生（§2.1） |
| **B · 源头结构化** | 数据生下来就是结构的，规则直接跑 | mCODE、CDS hooks、eCQM | R1 R2 | 证据活在叙事里；加录入负担的方案反复失败；指南一改规则全重写（R7 败） |

| **F · 跳过测量直接干预** | 让一致治疗成为默认（pathways、order sets） | 商业 oncology pathways | 绕开 R1–R4 | 不测量就看不见尾部；对正当偏离最粗暴；与 G2 互补而非替代 |

## 5 · 收敛：为什么是 D

选择逻辑一句话：**R3 与 R4 是反馈回路的约束瓶颈**——flag 不可信或不公平，tumor board 干预死于 alert fatigue，G2 断链——**而六条分支中只有 D 以 R3/R4 为第一性设计目标**。

D 与其余分支的真实关系（D 不是孤岛）：

* **D 包含 C**：presence 抽取已被解决（病理报告五变量 0.79–1.00 F1 `[SNIPPET, DeepPhe-CR]`），建在其上，不重做；
* **D 的部署形态是 E**：裁判者的分诊把人的核验集中在争议尾部——人没有被移出回路，被移到回路里最值钱的位置；
* **A 是 D 的 fallback**：登记 flag 慢但存在，做解耦的保底（§8）；
* **B 的失败是 D 的论据**：源头结构化败于"证据在叙事里 + 负担 + 脆弱"，恰是"合同 + 审阅"要在不改变临床工作流的前提下解决的同一组问题；
* **F 与 D 互补**：pathway 防患于未然，D 测量漏网与尾部。

## 6 · 技术方案：每个元素回应哪个缺口

### 6.1 两层架构

```
病历
  ↓  【直接证据层】唯一接触病历的层
四元组：(文档, 字段, 断言的值或缺席, 证据地位)
  ↓  【判断层】只在四元组上运算，不读病历 → 可离线单元测试
答案 / flag
```

归因立刻干净：四元组错 = 证据层问题（没找到 / 找到没读 / 地位判错）；四元组对而答案错 = 判断层问题（规则写错）。**这个二分是"错误分析自动化"的地基**（回应 §2.2 的开发成本）。

### 6.2 合同（contract）

人与机器阅读**同一份**工件（对照：登记手册是人读的散文，NLP 管线是机器的实现，无任何机制保证两者一致）。合同声明**三层强制等级**：

* **强制**——代码在其值上改变行为（格式检查、结局空间、覆盖 gate）：违反即拒绝；
* **渲染**——进入提示词、由模型负责（决策规则、边界案例）；
* **可背离**——方法性指导，模型可以不听，但背离可见。

证据地位（Standing）三分：**can establish / merely mentions / neither**，中间值不得折叠进第一个——复制前传的十次提及不是十份证据。

### 6.3 组合算子分类学（回应 §2.1 的变量边界）

变量的难度由其判断层的**组合算子**决定，而非模型能力：

| 算子 | 例 | 部署系统做了吗 |
|---|---|---|
| 佐证（多来源指向同一命题，强度叠加） | 淋巴结数≥12（单份病理报告） | **只有这个**（0.79–1.00 F1） |
| 仲裁（来源给冲突值，冲突规则选一个） | 初诊日期：细胞学 vs 活检 | 没有 |
| 去重 + 排序（同一事件多次提及） | 新辅助治疗先于手术 | 没有 |
| 推导（无文档断言答案，从他字段算出） | 分期组；class of case | 没有（class of case 零 NLP 工作） |

**已部署系统的变量集在算子一处封闭**——这解释了"哪些变量被自动化了"这个观测事实，且给出可证伪的预测：性能沿算子分层。

### 6.4 缺席主张与弃答（回应缺口一）

弃答是**有自己精确率/召回率的计分结局**，不是折进准确率的第三个桶。"无化疗记录"欠**覆盖证明**——声明范围内每条证据链都查过。三种状态必须可区分：**没有 / 没查 / 可能在别处**（第三种是碎片化在单系统标书内的诚实表达）。现有基准结构性做不到：主流队列筛选基准是二元的；临床 assertion detection 的标签空间预设概念已被提及。

### 6.5 分层推断（回应缺口二）

原因常无原文。允许推断，但推断是**被标记的答案类别**：

| 每个候选原因的结局 | 欠什么 |
|---|---|
| DOCUMENTED | 一条证据引用 |
| **INFERRED** | **每条前提各一条引用 + 对竞争候选的排除** |
| ABSENT | 覆盖证明 |
| CONTRADICTED | 双方引用 |

推断分两级：**声明规则**（合同列出的模式，确定性检查）+ **标记的自由推断**（接长尾，需裁决）；反复出现的自由推断**晋升**为声明规则——晋升记录本身是合同成熟的轨迹。（对照：神经符号试验匹配的溯因是**静默**补全缺失事实让逻辑闭合；这里的差别不是"不推断"，是"无标记的推断不存在"。）

推断的前提全是已见证的四元组，所以**推断住在判断层**——两层架构不被破坏。

### 6.6 裁判者（agent as judge，回应缺口三与 R3）

核验存在不对称性，它决定了裁判者必须自己是 agentic 的：

| 被核验的主张 | 核验操作 | 谁做 |
|---|---|---|
| 阳性（"化疗于 X 日启动"） | 查引用的文档是否含该值 | 代码，确定性 |
| **缺席**（"无拒绝文书"） | **独立反向检索——自己再搜一遍** | **必须是带工具的 agent** |
| **推断**（"推断为禁忌"） | 前提逐条核对 + 对抗性反证搜索 + 查排除义务 | 代码 + agent |

三个角色，各有边界：**确定性过程审计**（代码：完整性、found/read/cited、覆盖）；**对抗核验器**（不看金标准，立场是驳倒）；**分诊**（可以看分歧——分歧本身就是分诊的原料——把专家小时集中到争议尾部）。判定类别随数字走：LLM 裁决与确定性测量不得平均。

### 6.7 开发循环（回应 R7）

* **agent 是著合同期的探针**：模型自写查询暴露词表缺陷（实测案例：五词表在 27.6 万文档上漏 31.7% 患者的关键文档，因为有 carcinoma 没有 cancer，而系统在删模型自己提出的正确词 `[本仓库测量]`）；
* **两个无标注的成熟度信号**：跨运行**行为熵**（同 spec 同病历跑 N 次，答案分裂成不相容簇 = spec 不清晰——判断它不需要金标准）；**agent 臂与其合同编译臂的分歧**（B−C diff）——分歧非空，每条要么是合同漏声明、要么是 agent 乱走，**人只标注分歧**；分歧归零，合同已吸收 agent 所知，**可以停**；
* 这是手动循环（全量标注 → 人读轨迹做错误分析 → 改 spec）的自动化：省下的不只是标注工，更是资深的错误分析工。

### 6.8 flag 的定义（保护临床干预）

> **flag = 非一致 ∧ 无记录且不可推断的正当理由**，其中"无"字经裁判者独立反向检索核验。

这不是可选组件，是临床干预的守门员：有正当理由的偏离照样被 flag → tumor board 被淹没 → alert fatigue → 干预死于 co-design。统一句：**我们要求外科医生为偏离辩护之前，flag 自己先要能辩护。可问责审阅是可问责辩护的前提。**

## 7 · 必须证明什么

三个假设，全部是**任务结构层面**的命题（换癌种、换领域不需重证）：

**H1（过程效度可测）**：存在能区分"答案相同、过程不同"的测量。
验收 = **镜像对**：两份病历除关键事实外逐字节相同，捷径运行与完整运行提交同形状答案，仪器必须打出不同判定。**这是硬性终止条件：不能区分即仪器无效，主张收缩。**（不能报出干净结果的检查什么都没测——反之亦然：永远绿的列也该删。）

**H2（自适应性的边界可预注册）**：哪些变量需要自适应检索由组合算子决定。
验收 = **四臂阶梯**，同一合同同一评分器：

| 臂 | 检索 | 抽取 |
|---|---|---|
| D | 固定关键词 | 正则+词典+硬编码规则（零模型） |
| A | 固定关键词，读全部命中 | 单次 LLM 调用 |
| C | 模型自写查询，单轮 | 单次 LLM 调用 |
| B | 完整 agent | agent |

C−A 隔离查询构造的价值；B−C 隔离自适应循环的价值；预注册"B−C 随算子级别分层"。**任一方向都是发现**：若 B−C 处处 ≈0，结论为"该谱系可编译"，部署更便宜。

**H3（开发可无标注收敛）**：熵与 B−C 分歧追踪人工修订史；"仅裁决分歧"达到与全量标注等价的合同质量、成本为其一小部分。
验收 = 已有项目（肺癌）修订史的**重放** + 一个新变量的前瞻开发。

验证义务与必要条件的对应：

| 来自 | 证明 | 方式 |
|---|---|---|
| R3 | flag 扛得住对抗质疑 | H1 镜像对 + 缺席主张独立核验 + flag 精确率于专家裁决样本 |
| R4a | 正当偏离被识别 | §6.8 的 flag 定义 + INFERRED 裁决 |
| R4b | 碎片化不误判 | "可能在别处"作为可检测弃答类型（全景跨系统留后续） |
| R2 | 快到来得及 | 延迟测量：决策点 → flag 可用，对照登记的月级滞后 |
| R7 | 跟得上演化 | H3 |

**分级失败表**（没有一格是全损）：

| 失败模式 | 剩什么 | 可发表什么 |
|---|---|---|
| 镜像对不区分（H1 倒） | 引擎降级为检索完整性审计 | "过程效度在文档域不可测"= 对 Kundel 迁移的否定 |
| B−C 处处≈0（H2 一侧） | **利好**：可编译，部署更便宜的臂 | 任务结构发现 |
| 准确率不过金标准 | 降级为分诊/辅助模式（部署方自己的路线） | 四臂成本-质量报告 |
| 成熟度信号平坦（H3 倒） | 开发循环维持人工，引擎照常可用 | 替代终点的否定验证 |

## 8 · 与临床 Aims 的解耦

临床方的 Aim 2（tumor board 反馈干预 + accountable justification）与 Aim 3（CFIR 实施科学评估）。原则：**临床 Aims 的主设计不引用引擎；双方共享队列、各取对方的副产品。**

```
临床方的人工抽取（反正要做）──副产品：金标准──→ 引擎的验证数据
引擎（通过预设 gate 后）──副产品：时效与规模──→ 临床 Aims 的扩展
```

**Fallback 阶梯**：引擎全过 gate → 实时 flag（讨论当前患者）；部分通过 → flag + 分诊排序的人工复核；不过 → **既有登记的抽取员 flag**（干预降为回顾性反馈版，co-design / academic detailing / justification 全部照常可测，损失的只有时效）。**登记本来就在产生 flag，只是慢——引擎买的是时效与规模，不是干预的存在性。** 谁也不等谁。

## 9 · 诚实的反证（讨论者应该攻击的地方）

1. **多智能体已有已发表的负面结果**：BioNLP 2026 的多智能体癌症登记抽取输给自己的 baseline `[ACL Anthology 2026.bionlp-1.43, SNIPPET]`。本方案不主张多智能体更准——H2 恰是去测"何时值得"——但任何架构性承诺都要过这一关。
2. **自适应循环的增益可能在前沿模型上消失**：放射学多步检索的收益集中在中小模型，大模型"minimal change" `[SNIPPET, npj Digital Medicine (RaR), VERIFIED]`。对策：C−A 与 B−C 分开报，且 bridge 结构的失败有独立证据表明不随规模缩小（compositionality gap `[VERIFIED, EMNLP Findings 2023]`）。
3. **最近的竞争者未被读过原文**：ACIE（agentic 抽取，已部署于真实淋巴瘤登记研究，arXiv 2606.19602，**仅 arXiv 可见**）。其 96.5% 是"医生接受一个带引用的抽取"——未区分"证据对"与"答案对"，未报非 agentic 对照。**必须有人读原文**：若它含 single-pass 消融，H2 的定位要重写。
4. **完备性测量可能全绿**：本仓库自己的先行测量（42 次运行，检索失败为零）提示"答对了但没查"可能罕见。对策：kill condition 预设；且在四臂下"全绿"仍是发现（该谱系无过程差异）而非无信息。
5. **弃答对提示词高度敏感**（弃答率仅因措辞从 >50% 摆到 25% `[SNIPPET, 单源未核实]`）：所有弃答指标必须报告提示敏感性。
6. **原因类变量的人类金标准本身是推断且 IRR 低**（判断型变量 κ 低至 0.04–0.19 的先例 `[SNIPPET]`）：对策是患病率校正 kappa + 裁决式金标准，且承认这正是"过程测量比答案一致率更必要"的又一论据。

## 10 · 三个待决分岔（带推荐，供讨论）

1. **碎片化（R4b）进多深？** 推荐：本标书内做成可检测的弃答类型（"证据可能在别处"），全景跨系统核验（HIE 级）留下一份标书。激进方案（进来）会撑爆 scope；保守方案（不提）浪费最强的差异性偏倚论点。
2. **替代还是辅助？** 推荐：辅助 + 争议分诊。全自动的非正式门槛（95–98% F1，部署方作者转述的社区共识——**注意"informally"一词承重，不得写成 SEER 标准**）距离尚远；"把专家小时集中到争议尾部"是现在就能兑现的承诺。
3. **研究纲领的高度。** 三个假设写在任务结构层面：过程效度可测、自适应性边界由算子决定、开发可无标注收敛。CRC 是测试床不是边界——这决定五年后这套东西是"一个 CRC 工具"还是"病历审阅的测量科学"。

## 附 B · 术语表

* **沉默偏离**：未被注意、未被决定、未被记录的指南偏离。本项目的靶子。
* **可问责审阅（accountable review）**：以"审阅"为工作单元的测量——每个判定携带证据引用、覆盖证明、标记的推断，过程留痕可审计。
* **合同（contract）**：一个抽取问题的冻结声明（字段、决策规则、证据规则、冲突规则、答案成立的前提），人与机器读同一份。
* **Standing（证据地位）**：一份文档对一个字段的价值三分：can establish / merely mentions / neither。
* **镜像对（mirror pair）**：除一个关键事实外逐字节相同的两份合成病历；同形答案必须得到不同过程判定，是仪器的验收与终止条件。
* **完整答案（Complete Answer）**：运行检查过它所引用的每条冲突规则所依赖的事实。正确性与完整性正交——答案可以碰对。
* **四臂阶梯（D/A/C/B）**：零模型规则 / 固定检索+单次 LLM / 模型自写查询单轮 / 完整 agent。C−A = 查询构造的价值；B−C = 自适应循环的价值。
* **行为熵**：同合同同病历多次运行的答案分裂度。高熵 = 合同不清晰。无需金标准。
* **B−C 收敛**：agent 臂与合同编译臂的分歧归零 = 合同已吸收 agent 所知 = 修改可以停。
* **裁判者（judge）**：核验主张的第二 agent。缺席主张只能靠独立反向检索核验，故裁判者必须带工具。
